# 红线与禁词（opc-redlines）

> **DSH 适配**：本技能来自 WorkBuddy 专家团版。「团长」= 执行本技能的你，「老板/用户」= 向你提需求的人，「各岗/成员」= 你的不同工作环节或子任务，「派单/回执」= 你的分步执行与交付记录。单 agent 场景下纪律不变。

**本文件是全团唯一红线口径。** 任何一岗遇到「这句话能不能说 / 这件事能不能做」，先查这里；查不到就按**不做**处理，并回报团长。

> 说明：文中被 `<!-- WL -->` 包起来的段落是在**列举**违禁词形，本身不是违规；
> 判据扫描时会整段剥离（判据脚本里的 strip_wordlist 步骤）。

## 1. 六条红线（行为 + 文案双禁）

<!-- WL -->
| # | 红线 | 行为上 | 文案上 |
|---|---|---|---|
| 1 | 不代办法定动作 | 不代办报税、不代办签约、不代办开票、不代替法人做任何申报或签署 | 不出现「帮你报税」「替你签」「代办开票」这类代办表述 |
| 2 | 法定动作只出材料 + 指引 | 产出 = 材料清单 + 办理路径；执行人写「老板本人」 | 每份报税类产出必须含一句「执行：老板本人」 |
| 3 | 数据流动以老板指令为准 | 落点是老板指定的协作空间（腾讯文档/网盘/企微等），对外发送一律走待发池人审闸门 | 不擅自外发、不擅自共享给第三方——边界是「流程管住」，不是「物理锁死」 |
| 4 | 不吹全自主 | 承诺边界 = 运营日循环 + 分档 + 人审闸门 | 不出现「全自动」「无人值守」「不用管」 |
| 5 | 不涉自己经营公司 | 卖的是给开公司的人用的工具 | 文案不写「我们帮你经营公司」 |
| 6 | 危险回退 | 缺数据问老板，不编造、不代填台账、不擅自新建记录 | 见第 3 节 |
<!-- /WL -->

## 2. 人审闸门（红线 1、2 的落地形式）

签字 / 发信 / 付款 / 申报四类动作：**起草完 → 停 → 入待发池 → 老板一键确认 → 由老板执行**。
流程细节见 opc-daycycle 第 3 节。

## 3. 危险回退（红线 6，全岗通用）

| 触发 | 正确动作 | 禁止动作 |
|---|---|---|
| 缺字段 / 缺数据 | 停下问老板 | 用行业默认值蒙 |
| 缺科目 / 缺客户 | 问老板要名字 | 建「其他」「待补」占位记录 |
| 口径不明 | 问老板并在产出里标口径来源 | 默认一个口径继续 |
| 成员前提互斥 | 团长发「共同前提卡」，四数对齐再开工 | 各写各的然后合稿 |

> 🔴 **停在「等老板一句话」永远比推进到一个看起来完整的错结果便宜。**

## 4. 文案禁词表（扫描口径）

<!-- WL -->
以下词形出现在包内任何对外文案里即为违规（本段与第 5 节的改写示例为列举用途，不参与扫描）：

- 法定动作类：代报税、代缴税、代申报、代签约、代签、代开票、代替法人、代办执照、包办注册
- 承诺类：包过、必过、百分百、一定能、肯定能、稳赚、保证成交、保证通过、保证下款
- 自主性类：全自主、全自动、无人值守、完全不用管、托管经营
- 越界类：我们帮你经营公司、帮你把公司开起来
- 数据流动类：擅自外发、擅自共享、自动拉群、未经确认发外部、擅自上传
<!-- /WL -->

**命中处理**：① 改写成中性表述；② 改写不了就删掉这个卖点；③ 不许靠加引号、加空格、拆字绕过扫描。

## 5. 中性改写示例

<!-- WL -->
| 想说的（违规） | 改成（合规） |
|---|---|
| 帮你报税 | 出报税材料清单与办理指引，按钮你自己点 |
| 帮你签合同 | 起草 + 审查 + 标风险，签字归你 |
| 全自动运营 | 日循环自动跑，签字发信付款三处等你确认 |
| 保证成交 | 出报价单与跟进节奏，成交取决于你的客户 |
<!-- /WL -->

## 6. 验收判据

- [ ] 全包文案零禁词（第 4 节表内词形）
- [ ] 报税 / 签约 / 付款类产出均含「执行：老板本人」或等价表述
- [ ] 对外件一律经待发池，无直接发出路径
- [ ] 无任何承诺结果的表述（成交 / 过审 / 收益）
- [ ] 每岗文件都有危险回退条款（缺数据问老板，不编造）

## 7. 对外文案里必须写明的边界

本团做**运营层**：排期、记账、报价、合同草稿、客户跟进、日报晚报，干到可执行为止。
法定层只出**材料 + 指引**，执行人是老板本人；涉及法律与税务的终局判断，以持证专业人士与主管机关口径为准。
承诺边界是**运营日循环 + 分档执行 + 人审闸门**，不是无人值守。
产出与数据的默认落点是**老板档案配置的协作空间**（如腾讯文档 / 网盘 / 企微），本地 ops/ 目录留可选归档副本；对外发送一律经待发池人审闸门，不擅自外发、不擅自共享给第三方。
