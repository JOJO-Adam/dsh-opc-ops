# 产出形状与行业预填（opc-doc-shapes）

> **DSH 适配**：本技能来自 WorkBuddy 专家团版。「团长」= 执行本技能的你，「老板/用户」= 向你提需求的人，「各岗/成员」= 你的不同工作环节或子任务，「派单/回执」= 你的分步执行与交付记录。单 agent 场景下纪律不变。

**为什么要有这份文件**：六岗各自写各自的文件，老板拿到手是六种格式。统一形状之后，晚报能直接引用，台账能对上，老板不用重新学一遍。

## 1. 通用形状规则

- 每份文书**顶部三行**：用途 / 生成日期 / 依据文件（路径）。
- 字段缺失时写「待老板定」或「待补：xxx」，**不许**留空也不许编。
- 所有对外件生成后入 ops/90-待发池/，标收件方与待确认动作。
- 产出默认形态（红线 3）= 老板档案配置的协作空间里的在线文档（如腾讯文档）；本地 ops/ 路径为可选归档副本的形状约定。

## 2. 报价单（商务官）

```
用途 / 日期 / 依据（档案口径）
- 客户：<全称>
- 项目：
  | 项 | 数量 | 单价 | 小计 |
- 合计：<金额> <币种>
- 含税口径：含税 / 不含税（不明则写「待老板定」）
- 有效期：<日期或天数>
- 付款方式：<方式>
- 交付期：**待老板定**（商务岗不得承诺）
- 备注：需法务复核的条款位置
```

## 3. 合同草稿（商务官起草 → 法务官审）

```
用途 / 日期 / 依据
一、主体（甲方 / 乙方全称、联系人）
二、标的与范围
三、价款与支付（含税口径、账期）
四、期限与交付（**待老板定**）
五、违约与责任
六、知识产权
七、保密
八、争议解决
附：需法务复核的条款位置清单
```

## 4. 晨报（运营官供稿 → 团长收口）

```
## 晨报 · YYYY-MM-DD
一、昨日进展（≤5 条，每条指向一个文件）
二、今日三件事（≤3 条，对应待办表）
三、账面快照引用（截止时点 + 期末，来源 ops/20-台账/）
四、待老板确认（从昨日晚报继承，未处理的继续列）
```

## 5. 晚报（团长收口）

```
## 晚报 · YYYY-MM-DD
一、今日成果（每条：产出 + 落档路径）
二、明日计划（≤3 条，每条可转成待办）
三、待老板确认（每条：确认动作 + 依据文件 + 等你做的一下）
四、账面快照引用（截止时点 + 期末）
五、未完成与顺延（整条顺延，附理由）
```

## 6. 线索台账（商务官，CSV）

```
客户,来源,阶段,下一步动作,下次跟进日,备注
```

阶段取值：初次接触 / 报价后 / 交付中 / 回款提醒 / 已成交 / 已搁置。

## 7. 合规清单（法务官）

```
## 合规清单 · <行业专项>
- [ ] <项>：<结论> —— 依据：<出处 / 未核到出处>
```

每格必须有结论或有「未核到出处」标注，**不许留空**。

## 8. 行业预填 4+1

模板只预填**差异项**，不动七字段答案。

| 模板 | 预填的运营侧重 |
|---|---|
| **电商 / 跨境电商** | 订单流水台账、客服话术、上架排期、退换货流程、平台规则红线 |
| **自媒体 / 内容** | 选题库、发布排期、粉丝互动、商单接洽、广告与商单与付费收入台账 |
| **软件 / 技术服务** | 项目排期、需求文档、交付跟进、订阅收入台账、客诉收集 |
| **咨询 / 专业服务** | 报价单模板、合同范本、提案交付、工时账、复购跟进 |
| **通用空白** | 全字段手填（引导填空兜底），只保留通用红线 |

## 9. 验收判据

- [ ] 每份文书顶部三行齐全（用途 / 日期 / 依据）
- [ ] 缺失字段写「待老板定」，不留空、不编造
- [ ] 报价单字段完整（项目 / 数量 / 单价 / 有效期 / 含税口径 / 付款方式）
- [ ] 晚报含四段 + 每条成果有落档路径
- [ ] 对外件全部在待发池
