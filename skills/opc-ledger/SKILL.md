# 台账与快照口径（opc-ledger）

> **DSH 适配**：本技能来自 WorkBuddy 专家团版。「团长」= 执行本技能的你，「老板/用户」= 向你提需求的人，「各岗/成员」= 你的不同工作环节或子任务，「派单/回执」= 你的分步执行与交付记录。单 agent 场景下纪律不变。

**单一口径**：所有与钱有关的记录走这份规格，避免「两个人记两本账、对不上」。

## 1. 台账文件

- 路径：ops/20-台账/台账.csv（持续追加，不按天新建）
- 落点口径（红线 3）：台账默认落老板档案配置的协作空间（如腾讯文档，可在线协作），本地此路径 = 可选归档副本。
- 编码 UTF-8，逗号分隔，首行为表头，**表头一字不改**。

### 表头（10 列）

```
日期,凭证号,科目,对方,方向,金额,币种,含税口径,票据号,备注
```

| 列 | 取值 | 说明 |
|---|---|---|
| 日期 | YYYY-MM-DD | 业务发生日，不是记账日 |
| 凭证号 | 记-0001 起顺延 | 空号不补，改号留痕 |
| 科目 | 档案里的科目表 | **科目表里没有的科目不许用「其他」顶替，先问老板** |
| 对方 | 客户 / 供应商名 | 与 ops/30-客户/ 的名称保持一致 |
| 方向 | 收 / 支 | 只这两值 |
| 金额 | 数字，两位小数 | 不带货币符号、不带千分位 |
| 币种 | CNY / USD … | 档案未定时默认 CNY 并在备注写明 |
| 含税口径 | 含税 / 不含税 | 口径不明 → 问老板，不许默认 |
| 票据号 | 发票号或收据号 | 无票写「无票」并进票据清单的缺票条目 |
| 备注 | 自由文本 | 口径来源写这里 |

## 2. 对平判据（机器可判）

```
收合计 - 支合计 = 期末 - 期初
```

- **差额 = 0** → 对平，快照可出。
- **差额 ≠ 0** → **不许出快照**。做法：列出差额行（收合计 / 支合计 / 差额 / 疑似原因），进「待老板确认」清单。
- 抹平手段一律禁用：不许新增「其他」「待补」「调整」科目把差额吃掉。

### 校验顺序（每档记账后跑一遍）

1. 方向列只有「收 / 支」两值；
2. 金额列全是数字且 ≥ 0；
3. 日期列格式统一；
4. 收合计、支合计、差额三项算出来；
5. 差额为 0 才继续。

## 3. 现金流快照（时点口径）

快照必须写明**截止时点**，否则数字没有意义。

```
## 现金流快照 · 截止 YYYY-MM-DD（当日 / HH:MM）
- 期初：<金额> <币种>
- 本期收入：<收合计>
- 本期支出：<支合计>
- 期末：<期初 + 收 - 支>
- 应收未收：<笔数> 笔 / <金额>（明细见 ops/30-客户/线索台账.csv 与 ops/20-台账/票据清单.md）
- 口径：含税 / 不含税 —— <写明>
```

**三不许**：不许给预测、不许给投资建议、不许把应收当成已收写进期末。

## 4. 票据清单

- 路径：ops/20-台账/票据清单.md
- 分组：有票 / 无票（缺票）/ 待核（金额或口径不明）
- 缺票条目要写明「向谁要」（对方名称 + 要什么票）

## 5. 报税材料（红线区）

**产出只能是两样**：材料清单 + 办理指引。

```
### 报税材料 · <税种> · <所属期>
一、材料清单（勾选式）
  □ 收入汇总（来源：ops/20-台账/台账.csv，期间 …）
  □ 成本费用汇总（来源：…）
  □ 票据（清单见 ops/20-台账/票据清单.md，缺 N 张）
  □ …（按主管机关要求，以官方最新清单为准）
二、办理指引
  路径 / 时限 / 常见退回原因
三、执行：老板本人（本团不代办）
```

**不许出现**：应缴税额的确定性结论、减免结论、任何「帮你申报」的表述。
**必须出现**：以主管机关最新口径为准。

## 6. 验收判据

- [ ] 表头一字不改、列数 = 10
- [ ] 借贷对平（差额 = 0），不平则列出差额行
- [ ] 快照含截止时点与期初 / 期末
- [ ] 报税产出含「执行：老板本人」与「以主管机关最新口径为准」
- [ ] 零红线词（词表见 opc-redlines）
