# 日循环 SOP（opc-daycycle）

> **DSH 适配**：本技能来自 WorkBuddy 专家团版。「团长」= 执行本技能的你，「老板/用户」= 向你提需求的人，「各岗/成员」= 你的不同工作环节或子任务，「派单/回执」= 你的分步执行与交付记录。单 agent 场景下纪律不变。

**一句话**：老板说「开工」，团队按晨报 → 上午档 → 下午档 → 晚报跑完一天；老板只在两处介入（晨间计划确认、待发池一键确认）。

## 1. 四个节拍

> 落档口径（红线 3）：产出默认落老板档案配置的协作空间（如腾讯文档，首启第 8 字段指定）；下表 ops/ 路径 = 本地可选归档副本的路径约定。

| 节拍 | 谁 | 产出 | 落档 |
|---|---|---|---|
| **晨报** | 团长收口，运营官供稿 | 昨日进展 / 今日三件事 / 账面快照引用 | ops/50-日报/晨报-YYYY-MM-DD.md |
| **上午档** | 全团 | 客户跟进、文书生产 | 各岗目录 + ops/10-排期/派单记录.md |
| **下午档** | 全团 | 记账、排期更新、行业专项 | ops/20-台账/、ops/10-排期/ |
| **晚报** | 团长收口 | 今日成果 / 明日计划 / 待老板确认 / 账面快照引用 | ops/50-日报/晚报-YYYY-MM-DD.md |

## 2. 分档规则（为什么分两段）

单个会话有轮次上限（各岗 maxTurns 已按档位留出余量），所以一天拆两档：

- **档位切换点**：上午档收口时，团长写一份**档末交接**（已完成 / 进行中 / 未开始 + 各自依据文件），落 ops/10-排期/。
- **下午档开工**：团长**先读档末交接**再派活，不靠会话记忆。
- **跨天**：晚报的「明日计划」就是次日晨报的输入，次日开工先读晚报。

## 3. 人审闸门（三类动作，起草完必停）

| 动作类型 | 停在 | 老板要做的一下 |
|---|---|---|
| 签字（合同、协议） | 法务审完 + 草稿入 ops/90-待发池/ | 自己签 |
| 发信（报价、跟进、对外消息） | 草稿入待发池，标收件方与用途 | 一键确认后发出 |
| 付款 / 申报（转账、报税、开票） | 材料与指引备齐，标「执行：老板本人」 | 自己在对应系统操作 |

**待发池条目格式**：

```
### 待发 <序号>
收件方 / 用途 / 依据文件 / 待确认动作（发出 或 付款 或 申报）
正文：（草稿全文）
```

> 🔴 池子里的东西**只有老板能让它出池**。任何一岗自行发出 = 红线事故。

## 4. 留痕（抗幻觉的底层纪律）

- 每步产出**落文件**，路径固定（目录约定见团长角色文件的「落档约定」）。
- 派单必须落 ops/10-排期/派单记录.md（派给谁 / 原文 / 回报 / 时间）。只在会话里说「我派了」= 没派。
- 晚报里每一条「已完成」都要能指向一个文件；指向一个空目录 = 没做。

## 5. 抗漂移（长会话与压缩后仍不掉线）

会话被压缩、换档、或隔天回来时，**真相源顺序固定**：

```
工作区文件（档案 / 排期 / 台账 / 晚报）  ← 最高
        ↓
昨日晚报的「明日计划」
        ↓
会话记忆                                  ← 最低，冲突时丢弃
```

具体三条：

1. **每档开工重读档案**（不是只读一次）——压缩后档案是唯一没被压掉的东西。
2. **关键数字回读文件**：金额、日期、客户名一律从文件取，不从上下文取。
3. **发现冲突就报**：文件与记忆冲突时说一句「以文件为准，已按文件口径继续」，让老板知道发生过漂移。

## 6. 终止条件（日循环闭合）

晚报落档 + 待老板确认清单生成 + 明日计划写入 = **当天闭合，团队停**。

未闭合的三种正确处理：

| 情况 | 处理 |
|---|---|
| 等老板确认 | 清单里写明等的是哪一下，团队**停在这里**，不自行推进 |
| 缺数据 | 停下问老板，不编造、不建占位记录 |
| 时间片跑满 | 未完条目**整条**顺延到明日档，不许截半条交付 |

## 7. 验收判据（日循环合格线）

- [ ] 晨报含昨日进展 / 今日三件事（≤3）/ 账面快照引用
- [ ] 晚报含今日成果 / 明日计划 / 待老板确认 / 账面快照引用
- [ ] 每条派单有记录；每条「已完成」有文件
- [ ] 待发池非空时，晚报清单逐条列出待确认动作
- [ ] 档位切换有档末交接文件
- [ ] 零步骤重复：同一条任务同档内重试 ≤2 次

## 8. 反模式

- 跳过晨报直接干活 —— 老板看不到今天要发生什么，晚报也就没有对照物。
- 晚报只写「今天做了很多事」 —— 无文件指向，等于没做。
- 为了凑齐闭合把未完条目标完成 —— 这是全团最贵的一个谎。
